# Economics documents

Use one file per placement row. Shared header: method, sources, assumptions, exclusions, confidence, range, drivers, sensitivity, date, revision, and class.

Class is preliminary, refined, approved baseline, actual, or forecast.

Labor cost, velocity, and earned value use the formulas in `core/economics.xml`. Missing inputs stay blank. Unverified prices are provisional.

`BACKLOG_COST_ESTIMATE.md` is a companion. It does not add columns to the extended backlog CSV.
